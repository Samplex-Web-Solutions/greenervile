# Greener Vile - Investment & Performance Management Platform

A high-performance, secure web application built for **Greener Vile**. This platform handles partner authentication, investment tracking, and administrative oversight.

## 🚀 Tech Stack

* **Frontend:** React.js (Vite)
* **Styling:** Tailwind CSS
* **Backend/Database:** Supabase (PostgreSQL)
* **Authentication:** Supabase Auth with custom RLS (Row Level Security)
* **State Management:** React Context API

## 🛠️ Features

* **Secure Authentication:** Email/Password registration and login.
* **Identity Management:** Custom profiles table automatically synced with Auth via Database Triggers.
* **Admin CMS:** Institutional-grade dashboard for managing investor profiles and roles.
* **Responsive Design:** Fully optimized for mobile and desktop using a professional "Success Green" and "Slate" palette.
